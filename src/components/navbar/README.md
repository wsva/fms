App shell (fms-app style): `AppShell.tsx` owns the sidebar width/rail/mobile-drawer state and composes `Sidebar.tsx` (left navigation built from `menu.ts` — its `rootMenuItems` render as one-click rows above the collapsible `menuList` groups, with the login/logout row on top) and `TopBar.tsx` (back/forward + breadcrumb from `src/lib/nav-crumbs.ts` + PlanCountdown + theme). The sidebar is drag-resizable between 120 and 320 px and double-clicking its blank space toggles the 48 px icon rail; both persist in localStorage. On mobile the sidebar becomes a slide-in drawer.
